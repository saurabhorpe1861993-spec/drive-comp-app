# RideFare Assistant - Android APK

Real-time Ride Fare Evaluator & Driver Assistant with full-screen layman alert and giant Accept button.

## Automatic GitHub APK Build
This repository includes `.github/workflows/build-apk.yml`.
Whenever you push to `main` or trigger the workflow, GitHub Actions compiles `app-debug.apk` automatically in the cloud.

### How to get your APK:
1. Push this repository to GitHub.
2. Click the **Actions** tab on your GitHub repository.
3. Click the latest run **Compile Debug APK**.
4. Download the **RideFare-Assistant-Debug-APK** artifact.
5. Install on your Android phone!
